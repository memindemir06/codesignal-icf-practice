# Mock 5 — Working Hours Register

**90 minutes. One file: `solution.py`. Four levels.**

Two things make this one different from the rest of the kit, and both are deliberate:

* **Everything returns a string**, including numbers and booleans. `"true"`, `"42"`, `""`.
  Trap T2 lives here.
* The state is **intervals**, not scalars. Level 3 and 4 are interval arithmetic, not
  bookkeeping.
